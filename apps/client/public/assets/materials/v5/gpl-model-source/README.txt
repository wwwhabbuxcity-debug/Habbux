Reprodução independente (Node 22):
1. Guarde cleandb-models.json, converter.mjs.txt e reproduce-v5.mjs.txt juntos.
2. Renomeie os dois arquivos .mjs.txt removendo somente o sufixo .txt.
3. Execute: node reproduce-v5.mjs cleandb-models.json reproduced.tsv
4. Compare reproduced.tsv com gallaxys-gpl.tsv: são idênticos byte a byte.
O destino deve ser novo. Não são necessários banco, credenciais ou Gallaxys.
