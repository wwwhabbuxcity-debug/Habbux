# Proveniência dos modelos V3

| Conjunto | Evidência | Classificação | Ação |
|---|---|---|---|
| 64 modelos Gallaxys disponíveis no DB | SELECT read-only, tabela/ID e hashes no inventário; sem permissão individual encontrada | UNKNOWN | 0 convertidos; heightmaps somente backup referência |
| 63 modelos históricos Habbux | Recurso anterior preservado; origem/direitos individuais sem prova conclusiva | LEGACY_UNVERIFIED | Preservado conforme escopo; sem ampliar imports nem atribuir licença livre |
| 3 modelos hbx_* V3 | Geometria criada independentemente em tools/room-models/originals.json | ORIGINAL | Uso interno no projeto; 3 convertidos e validados |
| Conversor e validação V3 | Implementação nova Habbux sem código externo copiado | ORIGINAL | Código do projeto, sem nova dependência |

A existência de GPL nos repositórios Polaris/Octane não é permissão individual
para distribuir todos os heightmaps. Esta classificação registra evidências
observadas; não regulariza o pacote legado. Inputs AUTHORIZED futuros precisam
registrar autor, origem, licença aplicável e evidência de autorização explícita;
a string de status sozinha é insuficiente para passar pelo conversor.
