# ADR 0001: Java 25 sem preview

**STATUS:** Aceita

## CONTEXT

A JVM precisa de manutenção longa, toolchain comum e builds verificáveis para o emulador.

## DECISION

Usar Java 25, release 25, UTF-8 e recursos padronizados. Não compilar ou depender de preview.

## CONSEQUENCES

Recebe updates do JDK e adota recursos modernos estáveis. Exige JDK 25 no build; API não deve depender de detalhes específicos de uma distribuição. Não afirma compatibilidade anterior.
