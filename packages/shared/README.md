# Código compartilhado

Reserva para utilitários puros que tenham pelo menos dois consumidores reais e
semântica estável. Nenhum runtime ou barrel genérico foi criado. Não compartilhar
estado de gameplay, entidades mutáveis do emulador, segredos nem acesso direto a
banco. Contratos e IDs pertencem aos módulos específicos, não a este diretório.
